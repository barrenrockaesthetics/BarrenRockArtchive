# 2023.02 筆記合集

音樂會 Music Show :

和光同塵

藝術家 Artist :

611
曾永曦 Wilson Tsang

黃衍仁 Wong Hin Yan

日期 Date :

2023.02.03

611 嘅歌聲總會帶你連結草原同天空。地方唔大，我靠牆坐下，合埋眼，我想像我地都喺一個唔知去梗邊嘅貨車車櫃入面，聽住 611 講佢喺未上呢架車之前，點樣在外流浪，點樣聚於火堆，聽其他人歌唱，聽唔同語言嘅故事。上年睇左《草原上，我們開始跳舞》，係一套關於台灣文藝團體「野青眾」喺台北市中心找尋草原嘅紀錄片。佢地嘅「120草原自治區」最後失敗告終，但佢地問嘅問題始終未被解答：城市嘅草原去左邊呢？香港又有冇草原可以比歌聲，由一邊嘅地平線走到另一邊呢？

衍仁今次冇乜點唱新碟， set list 入面大多係 80 、 90 年代嘅廣東歌。今次佢亦特意要求人聲唔好似以前咁落好多 reverb ，只係用簡單嘅結他伴奏，用純粹嘅聲音去唱。佢相信，佢想唱咩歌，點唱，係關年紀事。當佢講呢句，我腦海即刻浮現 2022 Newsport Folk Festival 嘅 Joni Mitchell 點樣喺患腦瘤失聲過後，重新演釋 Both Sides Now 呢首佢 50 年前嘅作品。 Folk 唔係正正就係透過理解自己嘅聲音、自己嘅語言，將當下，同以往所累積嘅情感，全都灌輸入歌聲嘅一個 genre 咩？！亦所以 Folk 係幾咁同個人、同地方、同民族有關。衍仁決定重新演繹舊歌，係時間過後嘅選擇，唱嘅〈吓〉、〈何日〉、〈抉擇〉，自然會同同住一個地方、經歷同樣日子嘅我地有所共鳴。當佢唱〈難為正邪定分界〉嘅時候，佢所選擇嘅唱腔（壓低與否），選擇唱葉振棠定麥志誠嘅聲部（正或邪），都選擇左佢現在，係以咩視覺去睇呢個城市。 611 同 Wilson Tsang 嘅歌聲亦然，都係喺了解自己、經日子雕琢後所選擇嘅聲音，可以係韻律同故事共舞，亦可以係酒後，將聲線糊掉嘅滄桑感。

記得大學上堂曾經聽過一個講法係：香港千禧前後流行曲嘅其中一個分別，就係前者嘅旋律多數較簡單少字，音與音之間有更多空間，可以比歌手將情感放喺音與音之間，某程度上就係歌手有更多空間選擇唱法（真係唔記得邊個提出，你知嘅請話我知，補返 credit ）。呢個區分準唔準確，不在此談，但好似係個幾好嘅切入點去解釋點解 80 、 90 年代嘅廣東歌會被衍仁揀中，出現喺荔枝角，出現喺《和光同塵》。如果城市草原不再，咁香港嘅地貌又喺到孕育梗一啲，點樣屬於香港嘅旋律呢？當有日我地都身於異處，有日有幸相聚於火光之前，我地又會唱一首點樣嘅歌去講我地嘅故事呢？
